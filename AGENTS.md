# AGENTS.md

## Development rules

Agents working in this repository must follow the rules in [DEVELOPMNET_RULES.md](DEVELOPMNET_RULES.md).

## Commits

- Commit the work for each user prompt before responding. For a small or straightforward task, this is usually one commit.
- For complex tasks, make a separate commit after each major, independently reviewable step instead of waiting until all work is complete.
- Use a detailed commit message that explains what changed and why. Keep each commit limited to the files for that step; do not include unrelated working-tree changes.
- If the user explicitly asks not to commit, follow that instruction and report that the changes remain uncommitted.
